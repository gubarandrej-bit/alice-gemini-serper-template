# Яндекс Алиса + Gemini + Serper на Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fgubarandrej-bit%2Falice-gemini-serper-template&env=GEMINI_API_KEY&envDescription=%D0%9A%D0%BB%D1%8E%D1%87%20Google%20AI%20Studio%20%28SERPER_API_KEY%20%D0%BC%D0%BE%D0%B6%D0%BD%D0%BE%20%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C%20%D0%BF%D0%BE%D0%B7%D0%B6%D0%B5%20%D0%B2%20Settings%29&project-name=alice-gemini-webhook)

Готовый шаблон вебхука (0 внешних npm-зависимостей, Node.js 22) для навыка **Яндекс Алисы** с нейросетью **Google Gemini**, быстрым интернет-поиском, памятью о пользователе, голосовыми режимами и автоматическим обходом лимита ответа в 4,5 секунды.

---

## Что умеет шаблон

- **Умные ответы + естественная озвучка (`TTS`)** — модель отвечает живо и понятно на слух, а модуль `tts` автоматически раскрывает градусы (`+15°C` → *«плюс пятнадцать градусов»*), валюты, проценты и аббревиатуры (`GPT`, `Wi-Fi`, `ИИ`) с мягкими паузами.
- **Двойной поиск в интернете + кэш** — если указан `SERPER_API_KEY`, используется быстрый поиск Google через Serper с кэшированием частых запросов на 7 минут. Если ключа Serper нет — автоматически включается встроенный **Google Search Grounding** самой модели Gemini (достаточно одного `GEMINI_API_KEY`!).
- **Долговременная память между разговорами (`user_state_update`)** — навык запоминает ваше имя, родной город (для погоды и местных событий) и желаемую длину ответов между сессиями на колонке и в телефоне.
- **Чтение длинных ответов по частям («Дальше»)** — ответы длиннее 1024 символов не теряются: остаток сохраняется в `application_state` и дочитывается по слову **«дальше»**.
- **Фоновое додумывание сложных вопросов (4,5с+)** — если модель думает дольше окна ожидания Алисы, вебхук не сбрасывает запрос, а продолжает генерацию в фоне через Vercel `waitUntil` (до 9–10 с, в памяти или через Upstash Redis) и отдаёт готовый ответ по команде **«дальше»**.
- **Автоматический резерв модели (Auto-Fallback)** — при превышении минутного лимита (`429`) или перегрузке (`503`) запрос прозрачно переключается на резервную модель (`gemini-3.1-flash-lite`).
- **6 голосовых режимов со звуковыми эффектами Алисы** — обычный помощник, синхронный переводчик, детский сказочник, голосовая викторина (с победными фанфарами на правильный ответ), разговорная практика английского и генератор идей.
- **Мгновенные локальные команды и защита квоты** — команды **«повтори»**, **«который час?»**, **«какое сегодня число?»** отвечают за 1 мс без расхода токенов, а встроенный антиспам (`RATE_LIMIT_PER_MINUTE`) бережёт квоту ключа.
- **Интерактивная веб-песочница на `/`** — на главной странице вашего домена Vercel доступен полноценный чат-тестер диалога с кнопками, индикатором байтового размера `session_state` (`XXX / 1024 B`), просмотром `TTS` и озвучкой в браузере.

## Быстрый запуск за 2 минуты

### Вариант 1 — Кнопка One-Click Deploy
Нажмите кнопку **Deploy with Vercel** вверху страницы → войдите через GitHub → вставьте `GEMINI_API_KEY` → после деплоя откройте свой домен Vercel в браузере, скопируйте готовый **Webhook URL** с главной страницы статуса и вставьте его в настройках навыка в Яндекс Диалогах.

### Вариант 2 — Вручную через Fork
1. На GitHub нажмите **Fork** и создайте свою копию репозитория.
2. Откройте https://vercel.com/dashboard → **Add New… → Project** → импортируйте свою копию и нажмите **Deploy**.
3. В проекте Vercel откройте **Settings → Environment Variables** и добавьте (выбрав **Production**):
   - **`GEMINI_API_KEY`** — ключ из Google AI Studio: https://aistudio.google.com/app/apikey *(обязателен)*
   - **`SERPER_API_KEY`** — ключ из Serper: https://serper.dev *(по желанию; без него поиск работает через встроенный поиск Gemini)*
4. Откройте **Deployments** → нажмите **Redeploy** для последнего развёртывания и дождитесь статуса **Ready**.
5. Откройте свой домен Vercel в браузере — на панели диагностики нажмите **«Скопировать адрес»** (`https://YOUR-PROJECT.vercel.app/api`).
6. В Яндекс Диалогах в настройках **Backend** вставьте этот адрес в **Webhook URL**, включите галочку **«Использовать хранилище данных в навыке»** и сохраните изменения.

## Голосовые команды внутри навыка

| Что сказать Алисе | Что произойдёт |
| :--- | :--- |
| *Любой вопрос* | Ответ Gemini с контекстом беседы и автопоиском свежих фактов |
| **«Запомни мой город Новосибирск»** | Сохранит город навсегда (для вопросов *«какая сегодня погода?»* и событий) |
| **«Меня зовут Андрей»** | Запомнит ваше имя между разговорами |
| **«Отвечай кратко» / «Отвечай подробно»** | Настроит лаконичный или развёрнутый стиль ответов |
| **«Что ты обо мне помнишь» / «Забудь обо мне»** | Озвучит или очистит сохранённый профиль |
| **«Режим переводчика»** | Включит двусторонний голосовой переводчик (русский ↔ английский) |
| **«Детский режим» / «Режим сказочника»** | Простые объяснения и интерактивные сказки с выбором сюжета |
| **«Режим викторины»** | Интерактивная викторина со звуковыми эффектами Алисы |
| **«Практика английского»** | Разговорный тренажёр английского с мягкими подсказками |
| **«Режим идей»** | Генератор идей для подарков, рецептов и досуга |
| **«Обычный режим»** | Возврат к стандартному помощнику |
| **«Дальше» / «Продолжай»** | Чтение следующей части длинного ответа или получение додуманного ответа |
| **«Подробнее»** | Развёрнутое продолжение предыдущей мысли |
| **«Повтори» / «Скажи ещё раз»** | Мгновенный повтор последнего ответа помощника без расхода токенов |
| **«Который час?» / «Какое сегодня число?»** | Точное местное время и дата по часовому поясу колонки |
| **«Забудь» / «Новый диалог»** | Сброс истории текущего разговора |
| **«Помощь» / «Что ты умеешь»** | Краткая голосовая справка |
| **«Хватит» / «Стоп» / «Выйти»** | Завершение сессии навыка |

## Дополнительные переменные окружения (по желанию)

- **`GEMINI_MODEL`** — основная модель (по умолчанию `gemini-3.5-flash-lite`).
- **`GEMINI_FALLBACK_MODEL`** — резервная модель при `429/5xx` (по умолчанию `gemini-3.1-flash-lite`; укажите `none`, чтобы отключить).
- **`GEMINI_GROUNDING`** — `true` (по умолчанию) включает встроенный поиск Google в Gemini, когда не задан `SERPER_API_KEY`.
- **`ALICE_SKILL_ID`** — ID вашего навыка из Яндекс Диалогов для защиты вебхука от посторонних запросов.
- **`WEBHOOK_SECRET`** — секретный пароль для URL вида `https://YOUR-PROJECT.vercel.app/api?secret=ВАШ_СЕКРЕТ`.
- **`UPSTASH_REDIS_REST_URL`** и **`UPSTASH_REDIS_REST_TOKEN`** — опциональное подключение бесплатного Upstash Redis для межсерверного хранения фоновых ответов длиннее 4,5 секунды (без них фоновое додумывание работает в памяти процесса через `waitUntil`).

## Как проверить навык голосом

1. В Яндекс Диалогах выберите тип доступа **Приватный**, сохраните настройки и сделайте навык доступным для тестирования.
2. На колонке или в приложении Алисы войдите в тот же аккаунт Яндекса, что и в консоли разработчика.
3. Скажите: **«Алиса, запусти навык [активационное имя вашего навыка]»** и задайте любой вопрос.
4. Для локальной проверки кода разработчиками (нужен Node.js 22+): `npm test`.
